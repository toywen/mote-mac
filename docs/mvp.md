# mote MVP 功能定义

## 目标

mote 第一版在 Mac 上替换 Obsidian。它能打开任何一个 Obsidian 笔记库，用来日常读写。

`~/life-os` 是主要的测试笔记库，另外 4 个本机笔记库做补充测试。

验收标准是你连续一周记笔记，不需要打开 Obsidian。

本文用到的词：

- **笔记库**：一个装 Markdown 文件的文件夹，Obsidian 里叫 vault。
- **笔记**：笔记库里的一个 `.md` 文件。
- **双链**：`[[笔记名]]` 形式的链接。
- **Markdown 链接**：`[文字](路径.md)` 形式的链接。
- **反向链接**：链接到当前笔记的其他笔记。
- **实时预览**：边写边渲染。光标所在的行显示 Markdown 源码，其他行隐藏符号。
- **阅读模式**：只读，完整渲染整篇笔记。
- **属性**：笔记开头 `---` 之间的 YAML，也叫 frontmatter。
- **日记**：按日期命名、每天一篇的笔记。
- **笔记库配置**：笔记库里 `.obsidian` 文件夹中的 JSON 配置文件。

## 范围依据

范围按 2026-11-20 的数据定。数据来自 5 个本机笔记库的笔记库配置，以及下面这条命令的统计：

```sh
node tools/vault-audit.mjs ~/life-os ~/wiki ~/workspace/Pesemic ~/Downloads/workspace ~/Downloads/workspace/knowledge-base
```

| 事实 | 对范围的影响 |
| --- | --- |
| 双链约 1300 处，指向笔记的 Markdown 链接约 40 处，例如 `life-os` 有 23 处、`Pesemic` 有 11 处 | 两种链接都进 P0。Markdown 链接虽少，点不开或改名后失效都会丢数据 |
| `Downloads/workspace` 有 317 篇笔记用了 callout | 实时预览里的 callout 样式进 P0 |
| 图片引用超过 200 处 | 图片渲染进 P0 |
| 任务、表格和属性在 5 个笔记库里都常见，例如 `life-os` 有 300 个任务 | 三者都进 P0 |
| `life-os` 的编辑器处在实时预览，`workspace.json` 里是 `"source": false` | 实时预览进 P0 |
| 3 个笔记库的 `app.json` 开了 `"alwaysUpdateLinks": true` | 改名时更新链接进 P0 |
| 只有 `life-os` 有 `daily-notes.json` | 有配置按配置，没配置按 Obsidian 默认值 |
| macOS 和 Obsidian 都在用深色模式 | 深色模式进 P0 |
| 最大的笔记库有 604 篇笔记，2.67 MB | 性能目标留出余量，见"规模" |
| Dataview 查询只出现在 1 个笔记库的 9 篇笔记里 | Dataview 不做 |
| 没有 `.canvas` 文件，只有 1 个 `.base` 文件 | Canvas 和 Bases 不做 |

## 界面

```
┌────────────┬──────────────────────────────┬────────────┐
│ 文件树      │ 编辑器                        │ 反向链接    │
│            │ 实时预览，Cmd+E 切到阅读模式    │            │
│            │                              │            │
└────────────┴──────────────────────────────┴────────────┘
  Cmd+O 快速打开   Cmd+Shift+F 全文搜索   Cmd+Shift+D 今天的日记
```

界面跟随 macOS 的浅色和深色模式。

## P0：第一版必须有

### 笔记库

1. 打开任意一个文件夹作为笔记库。
2. 记住最近打开的笔记库，可以在它们之间切换。下次启动时打开上次的笔记库。
3. 忽略所有以 `.` 开头的文件和文件夹，和 Obsidian 一致。
4. 读取笔记库配置，但从不修改它。用到的配置有链接格式、改名时是否更新链接、新笔记位置和日记设置。某项没有配置时，用 Obsidian 的默认值。
5. mote 不在笔记库里写任何自己的文件。mote 的设置按笔记库存在 `~/Library/Application Support/mote`。
6. Obsidian、git 或其他程序改了笔记后，mote 立即显示新内容，目标是 100 毫秒以内。原因是 mote 编辑的是读进内存的副本，要靠 macOS 的文件变化通知重新读取。
7. 如果你正在编辑的笔记被外部改过，mote 不覆盖外部改动，并提示你选择保留哪一份。

### 文件树

1. 显示文件夹和全部文件，文件夹可以折叠。
2. 点击笔记，在编辑器里打开。点击其他文件，用 macOS 的默认程序打开。
3. 新建笔记和文件夹。新笔记的位置按笔记库配置决定。
4. 改名和移动笔记或文件夹。如果笔记库配置要求更新链接，mote 更新两类链接。一类是其他笔记里指向被移动笔记的链接。另一类是被移动笔记里的 Markdown 相对链接。
5. 删除笔记时，把文件移到 macOS 废纸篓。

### 编辑器

1. 实时预览渲染标题、粗体、斜体、`==高亮==`、行内代码、标签、双链、Markdown 链接、任务和图片。
2. 图片支持 `![](路径)` 和 `![[图片名]]` 两种写法。
3. 实时预览里的 callout 显示为带颜色和标题的块。
4. 实时预览把表格渲染成表格。光标移进表格时，显示表格的 Markdown 源码，用来编辑。
5. 点击任务复选框，切换完成状态。
6. 属性显示为 YAML 代码块，可以直接编辑。
7. 你停止输入后，mote 自动保存。切换笔记和退出 mote 时，也先保存。
8. 只打开、不修改的笔记，文件内容一个字节都不变。
9. 按 `Cmd+E` 切到阅读模式。阅读模式完整渲染表格、callout、Mermaid 图和 `![[笔记名]]` 嵌入。

### 链接

1. 点击双链或 Markdown 链接，跳到目标。链接带 `#标题` 时，跳到这个标题。
2. 目标不存在的双链用不同颜色显示。点击它，新建这篇笔记。
3. 链接目标不是笔记时，用 macOS 的默认程序打开。
4. 输入 `[[` 后，弹出笔记名补全。插入的链接格式按笔记库配置决定。
5. 支持 `[[笔记|别名]]` 写法。
6. 链接解析规则和 Obsidian 一致。验收清单第 2 条用 Obsidian 自己的解析结果做对照。
7. 右侧面板列出当前笔记的反向链接。两种链接都算。
8. 按 `Cmd+Option+←` 后退，按 `Cmd+Option+→` 前进，在看过的笔记之间切换。

### 查找

1. 按 `Cmd+O`，按文件名快速打开笔记。
2. 按 `Cmd+Shift+F`，全文搜索当前笔记库。点击结果，跳到匹配的位置。
3. 快速打开和全文搜索都支持中文。

### 日记

1. 按 `Cmd+Shift+D`，打开今天的日记。
2. 日记的文件夹和文件名格式来自 `daily-notes.json`。没有这个文件时，日记放在笔记库根目录，文件名是 `YYYY-MM-DD.md`。
3. 今天的日记不存在时，mote 新建这篇日记。

### 规模

1. 一个笔记库有 1 万篇笔记时，打开、搜索和改名都不卡顿。1 万是估计值，比本机最大的笔记库多一个数量级。具体指标在技术栈阶段定。

## P1：第二批

- 标签页，同时打开多篇笔记。
- 在渲染后的表格里直接编辑单元格。
- 属性面板，按 `.obsidian/types.json` 的类型显示日期、标签和多值字段。
- 从模板文件夹插入模板。
- 粘贴图片时，按笔记库配置保存到附件文件夹。
- 阅读模式渲染数学公式。本机有 3 篇笔记用到。
- 在笔记里嵌入视频和其他附件。
- 大纲、书签、出链和标签面板。
- 同时打开多个笔记库窗口。

## 第一版不做

| 功能 | 原因 |
| --- | --- |
| 图谱 | 不影响日常读写 |
| Canvas | 本机笔记库里没有 `.canvas` 文件 |
| Bases | 本机笔记库里只有 1 个 `.base` 文件 |
| Dataview | 只有 1 个笔记库的 9 篇笔记用到。查询块显示为代码块 |
| 插件系统和主题 | 第一版只服务你一个人 |
| Claudian 侧栏 | 2026-11-20 决定暂不处理 |
| 英语复习流程 | 2026-11-20 决定暂不处理，复习时继续用 Obsidian |
| 手机端、AI 和语音 | 放到第二阶段 |

## 备份

mote 不负责同步和备份。

`~/life-os` 现在靠 Obsidian 的 obsidian-git 插件每分钟 commit 并 push。这个插件只在 Obsidian 开着时运行。试用 mote 的那一周，让 Obsidian 在后台开着，备份就不会停。mote 自己的同步上线后，再关掉 obsidian-git。同步方案见[技术栈文档](tech-stack.md#同步方案)。

## 验收清单

第 1 到 6 条都在笔记库的副本上测试，不碰原始笔记库。

1. 打开 5 个本机笔记库的每篇笔记，没有报错。打开前后，用脚本对比全部文件的哈希值，全部不变。
2. 5 个笔记库里的每个双链和 Markdown 链接，在 mote 里跳到的目标和在 Obsidian 里跳到的目标相同。
3. 在 `~/life-os` 和 `~/workspace/Pesemic` 里，各改名或移动一篇有链接进出的笔记。用 `diff -r` 对比操作前的副本，只有这次移动和相关链接有变化。
4. mote 开着一篇笔记时，在 Obsidian 里修改这篇笔记。mote 立即显示新内容，两边都不丢字。
5. 在 `~/life-os` 里按 `Cmd+Shift+D`，日记路径符合 `daily-notes.json` 的格式。在没有日记配置的笔记库里，日记是根目录下的 `YYYY-MM-DD.md`。
6. 生成一个有 1 万篇笔记的笔记库，打开、搜索和改名达到技术栈阶段定下的指标。
7. 你连续一周只用 mote 记笔记。
