# 0002 编辑器、索引和阅读模式只用一个解析器

- 状态：已接受
- 日期：2026-11-20

## 背景

编辑器要标出链接，索引要提取链接，改名要替换链接原文。如果三处各用一个解析器，它们对"什么算链接"的判断会不一致。改名时就可能漏改或错改。

## 决定

- `src/core/markdown.ts` 定义 `@lezer/markdown` 的语法扩展：GFM 表格和任务、双链、嵌入、`==高亮==`、标签、callout、属性块。编辑器和主进程的索引用同一份配置。
- 不用 markdown-it 这类第二个渲染器。阅读模式就是关掉编辑的 CodeMirror，所有元素都按实时预览的方式渲染。

## 后果

- "什么算链接"只有一个定义。改名时替换的位置和编辑器里看到的链接一致。
- 阅读模式的渲染能力受 CodeMirror 装饰的限制。Mermaid 和嵌入要做成 CodeMirror 组件。
