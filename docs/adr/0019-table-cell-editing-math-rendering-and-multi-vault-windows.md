# 0019 表格单元格直接编辑、数学公式渲染与多笔记库多窗口

- 状态：已实现
- 日期：2026-11-22

## 背景

在第一阶段的优化中，用户提出三项关键需求：
1. 编辑表格时每次都要展开为源码，打断排版阅读。
2. 笔记中的 LaTeX 数学公式无法直接渲染预览。
3. 无法同时打开多个笔记库或独立工作窗口。

## 决定

1. **表格单元格直接就地编辑**：
   - 表格渲染控件将每个单元格设为可编辑元素。
   - 阻止编辑器按键冒泡，支持用 Tab 与 Enter 键切换单元格。
   - 失去焦点时自动将内容转义并写回 Markdown 源码。
   - 实时预览模式下保持表格排版，不再坍缩为纯文本。

2. **KaTeX 数学公式渲染**：
   - 核心解析器支持行内公式 `$...$` 与块级公式 `$$...$$`。
   - 使用 KaTeX 库渲染排版。
   - 实时预览中光标接触公式展开为源码，离开后重新渲染。
   - 阅读模式下始终渲染公式。

3. **多笔记库多窗口并行支持**：
   - 主进程管理多个应用窗口与笔记库实例映射。
   - 提供应用菜单快捷键 `Cmd+Shift+N` 快速新建窗口。
   - 各窗口独立进行文件读写与状态监听，互不干扰。
   - 资源协议服务所有已打开的笔记库文件。

## 理由

- 就地编辑单元格保持了所见即所得体验。
- KaTeX 解析速度快且不依赖外部网络。
- 多窗口支持满足了用户对照参考不同知识库的实际工作流。
