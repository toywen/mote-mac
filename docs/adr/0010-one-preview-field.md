# 0010 实时预览用一个字段和一张注册表

- 状态：已实现
- 日期：2026-11-20

## 背景

实时预览要渲染十几种元素：标题、链接、图片、callout、表格、任务、Mermaid 图、笔记嵌入。每种元素都要回答同一个问题：现在显示源码，还是显示渲染结果。如果每种元素各写一个 CodeMirror 扩展，这条规则就有十几份，迟早不一致。

## 决定

- `livePreview.ts` 里只有一个 `StateField` 画装饰。它遍历语法树一次。
- `renderers.ts` 是注册表，把语法节点名映射到渲染函数。加一种元素，就加一个文件，在注册表里加一行。
- 显示源码的规则只写在 `livePreview.ts` 一处，按元素算，不按行算。这和 Obsidian 一样。
- 块级组件（表格、图片、Mermaid 图、嵌入）在实时预览和阅读模式下都渲染。阅读模式只是从不显示源码、不能输入。

## 后果

- 每次改动都遍历整篇笔记的语法树。在 63 KB 的笔记里，每个键的主线程工作从约 5.0 毫秒变成约 6.2 毫秒（2026-11-21 实测，见 `docs/plans/step-3.md`）。
- 一个节点名只能有一个渲染函数。要接管一部分节点的元素，例如 callout 接管引用、Mermaid 接管代码块，就占住这个位置，把不归它的节点交回原来的渲染函数。
- 嵌入的笔记画在嵌套的 CodeMirror 视图里，用同一套扩展。所以没有第二个渲染器，ADR 0002 仍然成立。
