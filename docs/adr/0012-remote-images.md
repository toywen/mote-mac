# 0012 编辑器加载笔记里的 https 图片

- 状态：已实现
- 日期：2026-11-20

## 背景

5 个本机笔记库里有 287 处图片是 `https` 地址，大多来自网页剪藏。窗口的内容安全策略原来只允许本地资源，这些图片显示不出来。

## 决定

内容安全策略的 `img-src` 加上 `https:`。笔记里的 `https` 图片直接从网上加载。`http:` 图片不加载，5 个笔记库里没有。

## 后果

- 打开一篇有网络图片的笔记时，图片所在的网站会看到你的 IP 和打开时间。Obsidian 也是这样。
- 只放开了图片。脚本、样式和其他请求仍然只允许本地资源。
- 图片加载失败时显示一个带地址的占位框。这台机器连不上 `pbs.twimg.com`，这个域名下的 205 处图片现在都是占位框。
