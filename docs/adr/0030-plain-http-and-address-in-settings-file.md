# 0030 现阶段同步走 HTTP，服务器地址放在配置文件

- 状态：已实现，替代 0029 的"证书和域名"部分
- 日期：2026-11-25

## 背景

[ADR 0029](0029-public-registration-and-login.md) 定下：备案完成前先用自签证书，客户端把服务器地址和证书放进"高级"。

v1.0.9 按这个方案发布后，用户要先拿到服务器地址和一张 PEM 证书，填进"高级"才能登录。这一步对用户太重。

2026-11-25 你决定：现阶段允许同步走 HTTP，不要证书。服务器地址放在应用的配置文件里，不在界面上填。

## 决定

- 同步服务现阶段只开 HTTP，端口还是 8443。
- mote 内置服务器地址 `http://8.154.28.245:8443`。
- 要换地址，在 `~/Library/Application Support/mote/settings.json` 里写 `syncServerUrl`。地址只写到主机和端口。
- 同步设置面板去掉"高级"。面板只显示当前用的服务器地址，不能改。
- 登录状态里不再存服务器地址和证书。地址只有一个来源：配置文件，没有就用内置地址。
- `syncRemote` 保留证书固定的能力，只有 `tools/sync-sim.mjs` 用它。地址是 `https://` 又没给证书时，用系统信任的签发机构。以后换成域名和公共证书，只要改地址。

## 理由

- 用户只该记得用户名和密码，这一条来自 0029，没有变。
- 地址放配置文件，普通用户不用管它，要自己部署的人改一个文件就行。
- 保留 `https://` 的路，以后切回加密不用再改客户端的传输代码。

## 影响

- **密码、设备令牌和笔记内容在公网上是明文。** 同一个网络里的人和途经的运营商都能看到。拿到设备令牌就能读写这个账户的笔记库。这是你知情后接受的。
- 服务器 IP 出现在公开的安装包和仓库里。
- 换 IP 要发新版本，或者让用户改配置文件。
- 对公众开放前要换回 HTTPS：域名、备案、公共证书。0029 的这条上线前提不变。
- v1.0.9 存下的登录状态里有 `serverUrl` 和 `certPem`，新版本不读它们。设备令牌还能用，不用重新登录。
