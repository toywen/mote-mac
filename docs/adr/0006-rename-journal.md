# 0006 改名和移动用 journal 保证可以重跑

- 状态：已实现
- 日期：2026-11-20，2026-11-21 实现

## 背景

改名或移动一篇笔记，要移动文件，再改写很多篇笔记里的链接。如果中途 mote 崩溃或被关掉，链接会只改了一半。

## 决定

`move` 分三步，每一步都从当前磁盘状态推导，重复运行结果相同：

1. 在 `~/Library/Application Support/mote/journal.json` 记下 `{ from, to }`。
2. 移动文件。然后按索引找出所有指向旧路径的链接，以及被移动笔记里的 Markdown 相对链接，逐个改写。每个文件写入时都做哈希检查。
3. 删除 journal。

mote 启动时如果发现 journal，就重新执行第 2 步。已经改好的链接再改一遍，结果不变。

## 后果

- journal 存在 mote 自己的目录里，不写笔记库。
- 第 2 步必须是幂等的。改写链接的代码不能依赖"这个链接还没改过"。
