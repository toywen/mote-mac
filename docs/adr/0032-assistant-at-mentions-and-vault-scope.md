# 0032 助手支持 @ 随打随引与全库默认范围

- 状态：已实现，替代 0031 的范围选择部分
- 日期：2026-11-27

## 背景

ADR 0031 上线时，助手范围只有「这篇笔记」和「日记日期」。笔记库里不只有日记，未打开笔记时默认落到「本周日记」会让用户无法直接问项目、读书等其他笔记，也无法把多篇非日记笔记放进同一轮提问。

## 决定

- 在保留 40 万字全文发送、不截断、不做会漏内容的近似检索的前提下，将助手范围扩展为可混选组合的 `AiScope`（见 `src/core/ipc.ts`）。
- 用户在助手输入框打 `@` 或点「@ 引用」，可混选任意笔记、文件夹、标签、本周日记或整个笔记库，以标签条形式固定在输入框上方；按 `Backspace` 可移除末尾标签。
- 未固定任何标签时：打开了笔记就默认读当前笔记；未打开笔记就默认读整个笔记库，不再强绑定日记。
- 界面不展示字数统计，回答上方只显示「读了 N 篇」，超过 40 万字时仍由主进程拒绝并提示缩小范围。
- 标签索引复用共享的 `markdownParser`（见 `src/core/markdown.ts` 和 `src/core/noteIndex.ts`），同时读取正文 `#标签` 与 frontmatter 的 `tags`/`tag` 字段，懒计算并按需推给窗口。

## 理由

- 混选标签比单层下拉菜单更贴合跨文件夹、跨主题对比的真实提问，同时保持单行默认状态不喧宾夺主。
- 不展示字数减少界面噪音，字数上限作为主进程兜底保护即可。

## 影响

- `src/core/ipc.ts` 新增 `AiScopeItem`、扩展 `AiScope` 并新增 `listTags` 通道。
- `src/renderer/src/AssistantPane.tsx` 替换原三选一范围下拉菜单为 `@` 随打随引交互。
