# 0011 点击指向不存在笔记的链接时，新建这篇笔记

- 状态：已实现
- 日期：2026-11-20

## 背景

在此之前，mote 只在两种情况下写笔记库：保存你编辑过的笔记，执行改名或移动。Obsidian 里点击一个目标不存在的双链，会立即新建这篇笔记并打开。功能列表的链接-2 要求同样的行为。

## 决定

点击指向不存在笔记的链接时，mote 新建一篇空笔记，然后打开它。这是第三种写笔记库的情况。

- 新笔记的路径照搬 Obsidian 1.15.1 的 `openLinkText`，用到笔记库配置里的新笔记位置。
- 主进程只建空的 `.md` 文件，路径要通过 `parseVaultPath`。
- 缺的文件夹从笔记库根目录起逐级新建。已有的必须是真的文件夹，不穿过符号链接。
- 文件用 `O_CREAT | O_EXCL` 创建。这时笔记已经存在的话，直接打开它，不覆盖。

## 后果

- 点错一个不存在的链接，笔记库里会多一个空文件。Obsidian 也是这样。
- `CLAUDE.md` 和 `ARCHITECTURE.md` 的“只在两种情况下写笔记库”改成三种。
- 第 4 步的“新建笔记”可以复用主进程的这条写入路径。
