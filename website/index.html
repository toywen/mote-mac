文字是思考的容器。在 Mac 上，我们渴望一款轻盈、温润且纯粹的本地笔记工具，没有繁琐的云端登录、没有笨重的框架迟滞，更没有打乱思绪的多余修饰。

mote 的诞生只为一个使命：在 Mac 上重归书写的纯粹。打开任意本地 Markdown 文件夹，即可体验 860px 黄金阅读版心 与指尖触碰纸页般的温润字韵。

零破坏承诺 (Zero-Damage Invariant)
mote 绝不会向你的笔记库私写任何隐藏文件，也不擅自修改你的链接语法。所有设置与索引存放于 macOS 系统标准支持目录，你的知识资产 100% 自由纯净。

极致轻盈的本地优先架构

mote 基于纯粹的本地优先原则构建，完全遵循标准 Markdown 语法。双链解析毫秒级完成，经 5 个不同规模的测试笔记库、数万条双链全量测试，稳定顺滑。

即开即写，极度轻巧

Data Sovereignty & Non-Destructive

你的知识资产，100% 纯净与安全

很多笔记软件试图用私有格式将你锁定。mote 反其道而行之：以最克制的工程纪律，敬畏每一篇笔记的每一个字节。

01 / 原样保留

零改写，零破坏

只打开、不修改的笔记，磁盘文件字节保持绝对不变。自动保存精确保留文件原本的换行符（CRLF/LF）与 BOM 标记，拒绝悄悄修改元数据。

02 / 绝不污染

不在库内留下私有文件

mote 自己的配置、缓存与日志全部存放于系统标准支持目录，不向笔记库写入任何私有文件，随时换用任何编辑器打开依然完好如初。

03 / 冲突防卫

外部修改智能感知

与 Git、iCloud 或外部同步工具协同使用时，10.2ms 即可感知磁盘变化。遇到冲突绝不静默覆盖，优雅弹窗由你决定保留哪一份。

极致性能

毫秒级中文全文检索与快速打开

  • 快速打开（⌘O）：毫秒级模糊匹配，输入即可定位

彻底砍掉右侧死栏，灵动互联纽带

  • 860px 舒适阅读行宽，视线自然收敛
