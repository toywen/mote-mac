# mote 术语

文档、代码和对话都用这里的词。一个概念只用一个词。新概念第一次出现在文档里之前，先加到这里。

英文名是代码里的命名。还没有代码的概念，英文名是计划用的名字。

## 笔记库

| 术语       | 英文名             | 定义                                                                                                       |
| ---------- | ------------------ | ---------------------------------------------------------------------------------------------------------- |
| 笔记库     | vault              | 一个装 Markdown 文件的文件夹                                                                               |
| 笔记       | note               | 笔记库里的一个 `.md` 文件                                                                                  |
| 附件       | file               | 笔记库里不是笔记的文件，例如图片和 PDF。用 macOS 的默认程序打开                                            |
| 图片       | image              | 扩展名是 png、jpg、jpeg、gif、svg、webp、bmp 或 avif 的附件。编辑器经 `mote-file://` 读取并显示它          |
| 视频       | video              | 扩展名是 mp4、webm、mov、m4v 或 ogv 的附件。编辑器经 `mote-file://` 渲染播放器并播放它                     |
| 库内路径   | `VaultPath`        | 笔记库内的相对路径，用 `/` 分隔。除 `.mote/attachments/` 外不含以 `.` 开头的部分。由 `parseVaultPath` 创建 |
| mote 目录  | `.mote`            | 笔记库根目录下的隐藏目录。存放配置、工作区状态和附件文件夹                                                 |
| 附件文件夹 | attachments folder | `.mote/attachments/` 目录。集中存放笔记引用的图片与附件                                                    |
| 笔记库配置 | `VaultConfig`      | 笔记库里 `.mote/settings.json`（或兼读 `.obsidian`）中的 JSON 配置                                         |
| 日记       | daily note         | 按日期命名、每天一篇的笔记                                                                                 |

## 链接

| 术语          | 英文名        | 定义                                                                             |
| ------------- | ------------- | -------------------------------------------------------------------------------- |
| 双链          | wiki link     | `[[笔记名]]` 形式的链接                                                          |
| Markdown 链接 | markdown link | `[文字](路径.md)` 形式的链接                                                     |
| 嵌入          | embed         | 前面带 `!` 的链接，例如 `![[图片名]]` 和 `![](路径)`                             |
| 反向链接      | backlink      | 链接到当前笔记的链接，所在笔记可以是它自己                                       |
| 笔记索引      | note index    | 主进程内存里每篇笔记的规范化文本和链接。反向链接和搜索都查它                     |
| 链接解析      | resolve       | 从链接原文找到目标文件。规则以 Obsidian 的 `resolvedLinks` 为准                  |
| 链接去向      | `LinkDest`    | 点击一个链接后去哪里。有 4 种：笔记、附件、不存在的笔记、外部网址                |
| 子路径        | subpath       | 链接里 `#` 和后面的部分：`#标题`、`#上级#下级` 或 `#^块`。点击后跳到这个标题或块 |
| 导航历史      | history       | 这个窗口依次打开过的笔记和离开时的光标位置。后退和前进在它里面移动               |

## 编辑

| 术语       | 英文名          | 定义                                                                                                          |
| ---------- | --------------- | ------------------------------------------------------------------------------------------------------------- |
| 实时预览   | live preview    | 边写边渲染。选区碰到的元素显示源码，其他元素隐藏 Markdown 符号                                                |
| 显示源码   | reveal          | 实时预览里，一个元素露出自己的 Markdown 符号。选区碰到它时发生，阅读模式下从不发生                            |
| 阅读模式   | reading mode    | 只读，完整渲染整篇笔记。它是关掉编辑的同一个 CodeMirror 视图                                                  |
| 编辑器模式 | `EditorMode`    | 实时预览或阅读模式。按 `Cmd+E` 切换                                                                           |
| 装饰       | decoration      | CodeMirror 加在文字上的样式或组件，不改文字。实时预览靠它隐藏符号、加样式                                     |
| 渲染函数   | `Renderer`      | 把一种语法节点画成装饰的函数。注册表按节点名找到它                                                            |
| 嵌套视图   | nested view     | 笔记嵌入里画被嵌入笔记的只读 CodeMirror 视图。扩展和主编辑器来自同一个 `noteView()`，编辑器模式固定为阅读模式 |
| 属性       | properties      | 笔记开头 `---` 之间的 YAML，也叫 frontmatter                                                                  |
| 规范化文本 | normalized text | 编辑器里的文本。去掉 BOM，所有换行统一成 `\n`。保存时还原原来的 BOM 和换行符                                  |
| 基准哈希   | `baseHash`      | 打开或上次保存笔记时磁盘内容的哈希。保存前和磁盘哈希比较                                                      |
| 打开会话   | `session`       | 一篇笔记的一次打开，带着它的编辑器和保存。改名、移动和重新读盘不换会话，打开另一篇笔记才换                    |
| 冲突       | conflict        | 保存时磁盘哈希和基准哈希不同。mote 不覆盖，让你选保留哪一份                                                   |
| 外部修改   | external change | Obsidian、git 或其他程序对笔记库文件的修改                                                                    |

## 同步

这一节的概念都还没有代码，见 [step-10.md](docs/plans/step-10.md)。

| 术语       | 英文名          | 定义                                                                                            |
| ---------- | --------------- | ----------------------------------------------------------------------------------------------- |
| 同步服务   | sync service    | 跑在服务器上的进程。它存每个文件的最新内容和历史版本，并把改动通知各台设备                      |
| 同步模块   | sync module     | mote 主进程里的模块。它把本机笔记库的改动上传到同步服务，把同步服务的改动写进本机笔记库         |
| 设备       | device          | 连接同步服务的一份 mote 安装。每台设备有一个设备令牌                                            |
| 设备令牌   | device token    | 同步服务发给一台设备的密钥。设备每次连接都带上它                                                |
| 版本号     | `seq`           | 同步服务给整个笔记库的计数。它每接受一次改动，版本号加 1                                        |
| 历史版本   | revision        | 同步服务保留的一个文件的旧内容                                                                  |
| 同步状态表 | sync state      | 设备本地的表，存在 `~/Library/Application Support/mote`。记录每个文件上次同步的哈希和版本号     |
| 同步基准   | sync base       | 一个文件上次同步成功时的内容。三方合并用它当基准                                                |
| 三方合并   | three-way merge | 用同步基准比出本机和远程各自的改动，再把两边的改动合成一份                                      |
| 冲突文件   | conflict file   | 三方合并不能用时，存本机内容的新文件。名字是 `笔记名 (冲突 设备名 时间).md`。原文件保留远程内容 |
| 证书固定   | certificate pin | 设备只接受指纹和设置里一致的那张 TLS 证书                                                       |
